# 状态、记忆与上下文隔离

## 是什么

- **任务状态**：当前任务进展到哪一步、由谁负责、是否成功。
- **智能体上下文**：某个智能体执行当前工作所需的信息。
- **共享成果**：多个智能体需要复用的证据、文件或中间结果。
- **持久记忆**：跨任务保存、并在获得适当授权后复用的信息。

隔离的原则是：每个智能体只获得完成本次任务所需的信息。可以写成 `可见信息 = 必需的任务输入 + 允许访问的共享成果`。

## 与协同架构的关系

主子、并行和黑板等架构会产生不同的信息流；状态与上下文管理为这些信息流提供边界，避免重复读取、互相覆盖或误用旧版本。这是系统基础能力，不是另一种协同架构。

## 示例

写作智能体不需要检索智能体的每轮搜索过程，只需要已验证的政策证据、文件摘要和引用位置。可以用任务 ID 贯穿调用，为智能体分别维护上下文，用统一格式记录共享状态，并保存检查点以便恢复。
