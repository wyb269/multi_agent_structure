# MCP 和 A2A 的作用

## 是什么

| 名称 | 通俗理解 | 主要连接对象 |
| --- | --- | --- |
| MCP（模型上下文协议） | 让 AI 应用按统一方式使用外部工具和数据 | 智能体与工具、数据源 |
| A2A（智能体间协议） | 让不同系统中的智能体按统一方式发现能力、委派任务和交换结果 | 智能体与智能体 |

两者解决的是连接与通信问题。流水线、主子等协同架构解决任务如何组织和执行的问题，可以在同一系统中同时使用。

## 示例

可以通过 MCP 为数据库智能体提供查询工具，再通过 A2A 让其他业务系统调用这个智能体。是否需要 A2A，取决于智能体是否要跨系统互通；在同一个应用内部协作时不一定需要它。
